# 数据与研究方法

## 数据与时钟

使用课程Release的2026-09-23上证50数据包；输入SHA-256为`18c0e124a9c68eb2f77b965ca1f29c93bb30339d7db45245e1af3c0420c6c947`。三类文件共10,321,925行，逐笔事件10,069,294条。完整字段见`data-schema.md`，来源及参考见`references.md`。

新增及撤单采用`OrderOriNo`关联；`OrderNumber`是消息编号。成交中的`BidOrder/AskOrder`指向原始订单。连续竞价的主动指令可能先发布成交，剩余部分才出现ADD。因此完整成交后没有剩余ADD的主动号属于可观测数据语义。

快照标签缺少频道业务水位，直接比较保持原始结果。另计算标签所在秒内是否存在同样的十档及累计量状态；状态从较早事件持续到该秒也纳入存在性检查。扩窗结果单列保存。此类离线搜索仅承担诊断。

## 特征与划分

逐笔重建后生成一秒状态：最优报价、挂量、十档容量、档距、订单年龄、存续至少一秒的成熟量占比、成交及报撤单量、过去波动与动量。订单年龄扣除午休。行情延迟通过选择决策时刻减延迟之前最近的一秒状态实施，因此实际特征额外陈旧量介于0和1秒之间。

上午09:35—11:28校准；13:05—13:58验证选择；14:02—14:57日内留出。预测标签以1、5、30、60秒为期，跨入午休、集合竞价或超出可用连续时段的标签置空。边界保留两分钟隔离。课程Issue讨论在实现前已阅读全文，作为外部先验登记，日内留出按此背景解释。

岭回归以上午标准化参数拟合，正则强度从0.1、1、10中按验证均方误差选择，报告留出误差和相关。初始参数及线性求解均为确定性操作。该基线描述预测信息，执行策略使用另行固定的盘口紧迫性规则。

## 四项主检验

1. 最小合法数量的被动探针每分钟放置，等待30秒；比较方向调整后的失衡至少0.6与至多−0.6两组。分别报告全部起点、成交起点和未成交起点的同起点收益，以及实际成交后的价格表现。
2. 比较上午高深度阈值以上、新生且补量的盘口与成熟量占比至少80%的盘口，观察未来买一后退。补量定义要求过去一秒发生交易、同价深度维持、成熟量占比低于50%。
3. 上午固定过去五秒撤单量的分位数，比较高撤单与正常撤单，观察未来一档容量变化，并保存错后60秒的对照。撤单量覆盖全簿，后续容量为一档双边量，包含报价迁移影响。
4. 同频道连续同主动订单号聚合成交包，下一消息到达后确认边界。小量阈值来自上午，并限制在原最优档量以内；比较下一档距离一分与至少两分的即时两分以上中间价冲击。该比较包含交易规则决定的机械成分；成交包之后的1/5/30/60秒漂移另行检验。

事件按每股首个合格观察后60秒去重。探针主成交率使用30秒等待窗口、每分钟放置；辅助的成交后60秒标签最长延伸至起点后90秒，可能跨入下一探针，时间块重采样保留这类相关性。条件比较按证券、方向（适用时）、半小时时段、价差档及上午固定的深度档分层。保留双组都有观察的层，先在股票内等权各层，再对股票等权。同步五分钟时间块重采样1000次形成条件区间；匹配权重固定。主检验另用时间块贡献的近似正态p值及四主题BH校正。完整覆盖、原始均值、匹配均值、辅助期限及反证均保存。扩展敏感性以上午中位数固定近期波动、过去一分钟成交强度、档距及同侧可见队前量分档，另作联合匹配；覆盖减少单列。保存逐股效果及逐股剔除后的总体效果范围。

## 执行与账户

每股在09:35、10:05、10:35、11:05、13:05、13:35、14:05、14:35生成任务，买卖交替。母单目标按配置金额换成合法股数，科创板最低200股，主板按100股整手向上调整。八个时点是预定执行任务，验证区间并未用于筛选这些任务。

四种方案为立即主动、固定TWAP、被动等待与信号驱动。母单60秒截止，保护价固定为任务起点可见对手价外两分钱。子单数量上限取剩余母单量、可见对手十档量10%及过去一分钟成交量1%的最小值，再调整为合法数量。未达最小合法数量时保留剩余任务。

立即主动在起点尝试，并在截止前补单；TWAP每10秒依据累计计划尝试；被动方案排队并在截止前处理余量；信号方案在方向调整失衡达到上午80%分位数（限制在0.4至0.9）时撤销被动余量，收到撤单回报后尝试主动。每次决策先推进已到达的事件和回报。所有方案使用相同数量、时点、保护价和容量约束，运行两种排队模型及0/1/5倍延迟。额外成本压力按实际成交金额增加1bp，保持成交路径，用作成本覆盖。

全任务成本为方向调整后的“实际成交金额＋剩余股数×截止中间价−目标股数×起点中间价”，再加实际费用。分母是完整母单目标金额。成本先对股票内任务平均，再对股票等权。完整完成率、按股数完成比例、已完成任务的等待时间与剩余量同时保存。

每个方案另按交付时间把所有股票的预留和成交回报放进同一账户，核验现金、冻结及隔夜可卖量。基准账户现金1000万元，每股持有十笔母单的隔夜股数；参数可配置。增量相对持有初始底仓，在14:56:59估值，资金和订单记录逐条保存。研究任务按完整日程报告，上午与午后分段字段可供独立查看。

## 解释范围

历史路径固定；虚拟订单共享容量。订单改变后续参与者行为的反馈需要交互式市场模型。本项目保存保守排队与延迟压力情景，原始时间精度及一秒特征采样限制更短期限解释。

本项目使用一个交易日；时间块区间及日内验证描述该日条件证据。对账户身份、交易动机和跨日稳定性的判断需要其他来源。所有阈值、辅助结果和未完成任务均随实验保留。
